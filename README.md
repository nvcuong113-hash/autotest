# AutoTest — SRS-driven Web QA Platform

AI-assisted web testing platform that turns SRS documents into traceable test cases and executes browser tests with Playwright.

## MVP scope
- Upload and parse PDF, DOCX, XLSX, Markdown and TXT SRS documents.
- Extract requirements and maintain requirement-to-test traceability.
- Generate editable test cases using deterministic templates, with optional OpenAI API enhancement.
- Execute browser steps with Playwright and collect screenshots, logs and results.
- Persist projects, requirements, test cases and runs in SQLite.
- Export test cases and execution results to CSV/JSON.
